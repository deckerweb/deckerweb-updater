## English

# deckerweb Updater 2.2.1

- Fixed: Updated hosts can use their pinned updater beside an older loaded V2 copy.
- Improved: Release caches are isolated by implementation version.

Integration requires both the new runtime and the updated adapter. PHP 8.1 and host-dependent WordPress requirements remain unchanged.

## Deutsch

# deckerweb Updater 2.2.1

- Behoben: Aktualisierte Hosts verwenden ihren festgelegten Updater auch neben einer bereits geladenen älteren V2-Kopie.
- Verbessert: Release-Caches sind nach Implementierungsversion getrennt.

Erforderlich sind die neue Runtime und der angepasste Adapter. PHP 8.1 und hostabhängige WordPress-Anforderungen bleiben unverändert.
