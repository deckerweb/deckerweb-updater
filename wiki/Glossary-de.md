# Begriffe

[English](Glossary)

| Begriff | Bedeutung |
| --- | --- |
| Host | Plugin, das den Updater einbettet und seine Integration verantwortet. |
| Release-Asset | An einen GitHub-Release angehängtes ZIP. |
| Source-Archiv | Von GitHub erzeugtes Repository-ZIP für den Release-Ref. |
| Auth Provider | Installationsseitige Quelle eines repositorygebundenen Credentials. |
| Metadatencache | Temporäre Releaseinformationen, kein geladener Plugincode. |
| Textdomain | Vom Host verwalteter Übersetzungsnamensraum. |
| Sammelupdate | Natives WordPress-Update mehrerer Plugins. |
| Fähigkeitsprüfung | Prüfung, ob die bereits geladene Klasse die benötigte Option unterstützt. |
