# Glossary

[Deutsch](GLOSSARY-de.md)

| Term | Meaning |
| --- | --- |
| Host | Plugin embedding the updater and owning its integration. |
| Release asset | ZIP attached to a GitHub release. |
| Source archive | GitHub-generated repository ZIP for the release ref. |
| Auth provider | Installation-side source of a repository-bound credential. |
| Metadata cache | Temporary release information, not downloaded plugin code. |
| Textdomain | Host-owned translation namespace. |
| Bulk update | Native WordPress update of several plugins. |
| Capability guard | Check that the already loaded updater supports a required option. |
