# Security policy

Do not include tokens, signed download URLs, customer details or private repository contents in public issues. Report suspected credential disclosure privately to the maintainer using an existing private contact channel. Include only a redacted reproduction and the affected updater/host versions. Never post the credential itself.

2.1.0 is the official release. Every integrating host owns its candidate identity/version/compatibility validation and protected credential provisioning. See docs/INTEGRATION.md.
